# The Funniest One-Line Resignation Letter

A deterministic entry that writes one resignation letter from the point of view of a cron job to `entry.txt`.

## Run

    node main.ts

Output goes to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to redirect it elsewhere.

The program uses only Node built-ins. No dependencies, no network, no API keys. Output is identical on every run.
